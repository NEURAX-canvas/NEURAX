# NEURAX Benchmarks

**Key claim:** every model below was analyzed in **< 10 ms**, on a CPU, with zero GPU, fully deterministically.

## Reproduce

```bash
cargo install neurax-cli
neurax analyze examples/models/gpt3_175b.json -f json -o report.json
```

## Methodology

1. **Select model**: reference architecture from `examples/models/` (88 templates, 11 families)
2. **Run NEURAX analysis**: `neurax analyze <model>.json -f json`
3. **Compare**: predicted FLOPs / VRAM / latency against published training runs

## Metrics Validated

- **FLOPs**: floating point operations (forward + backward + optimizer)
- **VRAM**: peak GPU memory (weights, activations, gradients, optimizer states)
- **Latency**: analytical inference latency
- **Cost / Energy / CO2**: cloud cost, kWh, kg CO2 (requires `gpu_hour_usd` in config)
