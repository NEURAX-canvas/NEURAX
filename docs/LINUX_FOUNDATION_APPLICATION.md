## 📝 Dossier de Candidature

### 1. Description du Projet

NEURAX is an open-source **analytical compiler** for neural network architectures. It operates at **design time**, predicting training costs, memory usage, and performance before any GPU resources are committed.

**Tech stack:** Rust + MLIR/LLVM 18 + React 18 + FastAPI
**License:** MIT (100% open source)

---

### 2. Impact sur l'Écosystème Open Source

NEURAX contributes to the open source ecosystem by:
- **Democratizing ML architecture design** - making cost prediction accessible to all
- **Saving GPU costs** - helping engineers avoid wasted compute
- **Promoting responsible AI** - predicting behavior before deployment
- **Building on open standards** - Rust, MLIR, LLVM
