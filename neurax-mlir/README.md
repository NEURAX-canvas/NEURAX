# neurax-mlir

**MLIR code generation for NEURAX — neural architectures as MLIR dialects.**

Part of [NEURAX](https://github.com/rustnew/NEURAX), the analytical compiler for neural network architectures. This crate lowers a parsed `ModelConfig` into **MLIR** (Multi-Level Intermediate Representation) using custom NEURAX dialects, with multi-target backends (CPU, CUDA, Vulkan, Metal, ROCm) and IREE integration.

> **The vision:** the analytical pipeline tells you *what* the model costs; MLIR lowering tells you *how* it would execute. Same source of truth, two views.

## What's inside

- **14 NEURAX dialects**: architecture, graph, tensor, operator, compute, memory, hardware, parallelism, cost, report, data, training, optimization, utils
- **Multi-target lowering**: `CpuBackend`, `CudaBackend`, `VulkanBackend`, `MetalBackend`, `RocmBackend`
- **IREE integration**: `IreeCompiler`, `IreeDevice`, `IreeTarget` for cross-platform deployment
- **Lowering passes**: `ArchitectureLowering`, `OperatorLowering`, `MemoryLowering`, `HardwareLowering`, `ParallelismLowering`
- Built on [`melior`](https://crates.io/crates/melior) (safe MLIR bindings)

## Installation

```toml
[dependencies]
neurax-mlir = { git = "https://github.com/rustnew/NEURAX", package = "neurax-mlir" }
```

## Quick start

```rust
use neurax_mlir::{compile_model_to_mlir, NeuraxContext};
use neurax_parser::parse_model_config;

// Parse a model (see neurax-parser)
let config = parse_model_config(MODEL_JSON)?;

// Create the MLIR context
let ctx = NeuraxContext::new();

// Compile to textual MLIR
let mlir = compile_model_to_mlir(ctx.as_context(), &config)?;
println!("{}", mlir);
```

## Example output

```mlir
// Generated by NEURAX MLIR
"neurax.arch_model"() {
  model_name = "tiny-gpt",
  model_type = "transformer"

  layer_id = "attn_0",
  layer_type = "attention",
  input_shape = [128, 768],
  output_shape = [128, 768]
} : () -> ()
"neurax.compute.flops"() { total_flops = 5.18e10 } : () -> ()
"neurax.memory.peak"() { peak_vram_bytes = 75536640 } : () -> ()
```

## Target backends

```rust
use neurax_mlir::targets::{CudaBackend, TargetBackend};

// Lower to CUDA
let cuda = CudaBackend.lower(&mlir_module)?;
println!("{}", cuda);
```

## IREE integration

```rust
use neurax_mlir::iree::{IreeCompiler, IreeDevice, IreeTarget};

let compiler = IreeCompiler::new();
let target = IreeTarget::Cuda; // or Vulkan, Metal, Cpu
let compiled = compiler.compile(&mlir_module, target)?;
```

## API overview

| Item | Description |
|------|-------------|
| `compile_model_to_mlir(ctx, config) -> Result<String, String>` | Model → textual MLIR |
| `NeuraxContext::new()` | MLIR context wrapper |
| `NeuraxModule` | MLIR module wrapper |
| `TargetBackend` trait | `lower()` for each backend |
| `CpuBackend` / `CudaBackend` / `VulkanBackend` / `MetalBackend` / `RocmBackend` | Concrete backends |
| `IreeCompiler` / `IreeDevice` / `IreeTarget` | IREE deployment |
